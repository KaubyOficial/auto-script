# Modelo 1 — Dicas Práticas (Padrão)

```
#### 1. Gancho Impactante (80 palavras)

1. Abertura com situação atual, gerando identificação ou citando dados concretos
2. Autoridade do expert citado (se houver)
3. Afirmação forte ou controversa para gerar tensão
4. Promessa específica do que será entregue até o final do vídeo
5. Confirmar o título do vídeo repetindo ele, mostrando que não é clickbait
6. Usar de identificação do que a audiência está pensando ou sentido

Não necessáriamente nessa ordem, mas precisa incluir todos.

---

#### 2. Dicas Práticas (CONTEÚDO PRINCIPAL: 1700 palavras)

- Forneça uma estratégias simples para alcançar o marco.
- Separe os principais conteúdo em passos e itens de lista e quebre cada passo em partes detalhadas (com contexto, prática, exemplo, relfexão, oque - porque -como, etc.)
- Termine cada tópico interligando com o próximo abrindo um loop
- Manter explicação simples para mesmo um não investidor e leigo conseguir entender. Sem muitos termos técnicos (e caso usar algum, sempre explicar).

---

#### 3. Último Ato (50 palavras)

- Recapitule os principais pontos enquanto passa a mensagem final.
- Inclua um CTA direto para inscrição, e curtida. De modo que tenha relação direta com o vídeo e justificativa plausível para fazer sentido para pessoa clicar.
- Inclua uma abertura de loop para assistir outro vídeo em seguida.
```
